# Parrocket production brief

Owner-supplied Rocket Parrot, 0.45 m, 4.8 kg. Preserve the rounded royal-blue body, white face/belly, teal iris, red cheek and conical rocket beak with dark collar, three blue/yellow/red crest feathers, teal/yellow wing feathers, charcoal feet and red/orange/yellow rocket-feather tail with striped collar. No crystals, armor, detachable rockets or creature substitution.

Prepare shared optional assets without changing the active eighteen-species roster or existing encounters. Runtime species IDs remain pack-owned. A reusable JSON definition will use `parrocket`, primary Fire and existing move rules; Air is a design trait, not an implemented second combat type. Future authors choose habitat, acquisition, encounter balance and pack availability deliberately.

Portrait: the supplied three-quarter left-facing design, isolated on real transparency with no ground shadow. Combat: four authored poses in each of idle, attack, hit, faint and capture; same left-facing body identity, actual foot motion and expressive recovery. Directional movement: eight distinct views, each neutral planted idle followed by four alternating-foot walking poses. North shows the back, northwest a rear-left view, west a left profile, southwest a front-left view; their eastern counterparts are corresponding actual views. South faces the viewer. Match the game's row order, shared scale and bottom-center feet. Tail feathers remain part of the body and may brighten during attack, never transform into a different object.

Leave broad transparent gutters between every source pose. Export by explicit reviewed cells with one scale per sheet, preserving appendages and rejecting adjoining fragments. Review at 37-pixel follower and 115-pixel battle widths, including west versus northwest. Preserve supplied reference bytes and exact generation instructions. Technical/internal review is separate from owner taste approval.

## Use in a future map or adventure

The shared manifest IDs are `creature-parrocket` (portrait), `creature-parrocket-combat` (four columns × five action rows) and `creature-parrocket-follower` (five columns × eight direction rows). All are optional resources. The normal eighteen-species roster and existing maps are unchanged. Open `dist/parrocket-preview.html` through a local server to inspect all sixty poses and the shared animation renderer, including reduced motion.

Copy the exact object from `dist/resources/creatures/parrocket.json` into the chosen pack's `registries.json` species array. Add `parrocket` to that pack's `index.json` species list and add `{"species":"parrocket","weight":1}` to a reachable map zone's pool. Choose its encounter level, rarity and habitat deliberately; the supplied 38 HP / 13 attack / 7 defense are a starting tuning, not a playtested new encounter. Keep the stable ID after players can capture it. Run `npm run pack -- refresh-manifest <pack-folder>`, then `npm run pack -- validate-pack <pack-folder>` before building the pack. See `docs/PACKS.md` and `docs/MAP_FORMAT.md` for the existing contracts.

The engine selects its `-combat` and `-follower` resources by species ID, with portrait fallback if an optional sheet is unavailable. Existing Fire material effects accompany Element. The definition reuses Ember spark; the owner's Fire/Air reference does not grant a second combat type. “Fast scout” is descriptive: no new speed stat, flying collision, scouting AI or map-unlock ability is implemented. Height 0.45 m and weight 4.8 kg are reference design notes, not new gameplay fields.

For scenery-only placement, a map prop can reference `"sprite":"creature-parrocket"` with an authored width and location; a portrait alone does not create a capturable creature. Review the selected context at gameplay scale. Owner input provenance means supplied for this task; original copyright/license history was not supplied and is not inferred. Exact owner JPEGs, generation prompts, immutable generated drafts and spacing revision, export settings and internal evidence are retained.

Reproduce or check pixels with `python3 art/characters/export-parrocket.py` or `python3 art/characters/export-parrocket.py --check`. The exporter reuses existing complete-pose extraction, one nearest-neighbor scale per sheet and four transparent pixels on every cell edge. Editable twins are under `art/assets/source/parrocket/`. Internal review confirms identity and frame usability and does not claim owner taste approval.
