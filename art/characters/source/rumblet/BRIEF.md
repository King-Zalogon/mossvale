# Rumblet resource production brief

Owner references: the two inline Rumblet boards supplied in this conversation. Original image binaries are unavailable locally; generated adaptations must not be described as original reference files.

Preserve a low compact brown quadruped with sturdy cream-tipped feet, cream muzzle/inner ears, expressive eyes, angular brown back tuft and a short tail. The large gray frontal impact plate has one orange central accent and remains attached to the head. Keep simple crisp pixel shapes and a consistent silhouette/palette at gameplay size.

Deliver transparent portrait; eight anatomically rotated follower views (N, NE, E, SE, S, SW, W, NW), each planted idle plus four alternating gait poses; and four poses in each shared combat state (idle, frontal charge attack, hit/brace recovery, faint, capture/cooperative cheer). Rear views show back anatomy rather than a front plate pasted on the body. No shadows, text, grid lines or unrelated effect debris. Leave generous transparent source gutters and at least four transparent output edge pixels. Inspect with the shared renderer at 37px follower and 115px combat widths.

Stage as optional importable resource only. Stone is a provisional primary type matching the impact/brace theme, using existing stone-tumble; no Beast element, starter selection, new rules, evolution relationship or default-map encounter is implied. Future map authors review balance and type before importing.

Retain exact generation prompts, initial sources and any spacing revisions; reproducible export profiles; and honest internal technical/visual decisions. Owner taste remains pending until explicitly reviewed.
